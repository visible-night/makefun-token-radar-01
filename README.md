A token launch radar: it ranks pre-token protocols by an implied value calibrated from the snapshot's own live-token market caps, and gives every protocol a concrete farm plan with costs and times. The board covers all 40 watchlist protocols plus the 160 highest-implied-value pre-token protocols below the watchlist floor, in a sortable, filterable dashboard with a detail view per protocol and a model sandbox.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
